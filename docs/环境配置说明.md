# 智安工坊环境配置说明

## 1. 运行环境

- 操作系统：Windows 10/11 推荐
- Python：3.12.7，最低建议 3.10+
- 浏览器：Microsoft Edge、Google Chrome 或其他现代浏览器
- Git：用于保存开发记录和提交代码仓库
- 数据库：当前版本不使用数据库

## 2. 前端环境

- 前端框架：无，使用原生 HTML5、CSS3 和 JavaScript ES2020+
- 构建工具：无，浏览器直接加载 Flask 提供的静态文件
- 前端入口：`app/templates/index.html`
- 前端脚本：`app/static/app.js`
- 前端样式：`app/static/styles.css`、`app/static/insights.css`

## 3. 后端环境

- 后端框架：Flask 3.1.3
- 运行入口：`run.py`
- API 路由：`app/main.py`
- 检测引擎：`app/scanner.py`
- 项目洞察：`app/insights.py`
- PDF 报告：`app/reports.py`
- 默认地址：`http://127.0.0.1:5000/`

## 4. 数据库配置

当前版本没有数据库，扫描结果、人工复核状态和扫描历史保存在 Flask 进程内存中。关闭后端进程后，运行期间的临时历史会清空；上传的源代码不会被系统写入数据库。

## 5. 安装依赖

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

主要依赖：

- Flask：网页和 API 服务
- reportlab 4.5.1：生成中文 PDF 审计报告
- python-dotenv：读取本地 `.env`
- python-docx：项目材料辅助生成
- pytest：自动化测试

## 6. 环境变量

在项目根目录创建 `.env`，内容如下：

```text
DEEPSEEK_API_KEY=你的DeepSeek密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
HOST=127.0.0.1
PORT=5000
FLASK_DEBUG=0
```

`DEEPSEEK_API_KEY` 是密钥字符串，不是 URL。`DEEPSEEK_BASE_URL` 是接口地址。真实密钥不能提交到 GitHub。

## 7. 启动方式

### 启动后端和网页

```powershell
python run.py
```

本项目没有独立前端启动命令，因为 Flask 会同时提供前端静态文件和后端接口。启动后访问：

```text
http://127.0.0.1:5000/
```

### 启动数据库

无数据库，不需要启动数据库服务。

### 配置 AI 模型

在 `.env` 中填写 `DEEPSEEK_API_KEY`。系统启动后右上角会显示模型配置状态。点击风险项底部的 DeepSeek 按钮即可调用 AI 建议。系统会对发送内容进行临时脱敏，不会自动修改源代码。

## 8. 测试命令

```powershell
python -m pytest -q
```

当前项目包含扫描规则、风险评分、依赖分析和 Git 证据的自动化测试。
