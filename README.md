# 智安工坊——AI 安全开发协作平台

智安工坊面向大学生和教师，把代码安全审计变成可理解、可复核、可留档的 AI Web 工作流。平台保留 CodeGuard 代码安全审计引擎，支持文本粘贴和 ZIP 项目上传，能够识别 API Key、Access Key / Secret Key、数据库账号密码、JWT Token、邮箱、手机号以及疑似高熵凭据，并提供风险分级、代码行定位、人工复核、修复建议和 PDF 审计报告。

## 项目定位

平台的目标是把代码安全审计变成一个完整的教学协作流程。检测引擎由规则信号、代码上下文、文件类型和疑似凭据特征组合评分，不依赖单一正则表达式。新版增加扫描历史对比、依赖清单卫生检查、Git 开发过程证据展示和项目级统计。DeepSeek API 只用于生成更具体的教育性建议，系统没有自动修改源码的功能。

## 运行方式

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
python run.py
```

打开浏览器访问 `http://127.0.0.1:5000`。

如需使用 DeepSeek 建议功能，请在 `.env` 中填写 `DEEPSEEK_API_KEY`。真实 API Key 不要提交到 Git，也不要粘贴到聊天记录或申报材料中。未配置 Key 时，系统仍可完成本地检测，并使用内置修复建议。

## 功能说明

1. 文本粘贴：输入文件名和代码，点击“开始检测”。
2. ZIP 上传：上传不超过 20 MB 的项目压缩包，系统只读取支持的文本代码文件。
3. 风险结果：点击问题清单中的风险项，查看文件、行号、风险类型和原始代码行。
4. 人工复核：可标记为待确认、已确认、误报、已修复或忽略本次。
5. 修复建议：使用内置建议，或在配置 DeepSeek 后请求更具体的中文建议。发送给模型的临时上下文会脱敏，源代码保持不变。
6. 项目洞察：查看依赖清单、版本范围提示、Git 历史证据和扫描前后变化。
7. PDF 报告：点击“导出 PDF 报告”，生成适合课程作业和毕设存档的审计报告。

## 设计边界

- 平台只做防御性代码审计，不验证密钥是否真实有效。
- 平台不会自动修改、覆盖或回写用户源代码。
- 结果需要人工复核，不能替代正式的代码审计、密钥轮换和权限治理。
- ZIP 读取包含路径穿越防护，不扫描 `.git`、`node_modules`、虚拟环境、构建目录和二进制文件。

## 目录结构

```text
app/
  main.py       Flask 路由和上传处理
  scanner.py    原创混合检测与风险评分
  insights.py   依赖清单、Git 历史和项目洞察
  llm.py        DeepSeek 调用与传输脱敏
  reports.py    PDF 审计报告
  templates/    页面模板
  static/       静态前端
tests/          自动化测试
data/           演示数据
```
